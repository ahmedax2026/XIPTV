# X IPTV website

Upload these files to the `xiptv.live` hosting root:

- `index.html`
- `en.html`
- `about.html`
- `privacy.html`
- `terms.html`
- `robots.txt`
- `sitemap.xml`
- `site.webmanifest`
- `assets/`

Keep your live `logo.png`, favicons, and Google Search Console verification file in the same root.

After upload, submit `https://xiptv.live/sitemap.xml` in Google Search Console and request indexing for the homepage.
